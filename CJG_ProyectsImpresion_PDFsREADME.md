# PDF Print Manager 🖨️

Professional batch printing solution for managing PDF print jobs efficiently.

## Features ✨

- **Print Queue Management**: Add, remove, and manage multiple PDF files
- **Drag & Drop Support**: Easy file addition with drag and drop
- **Print History**: Track all print jobs with detailed logs
- **Scheduler**: Schedule print jobs for specific times
- **Multi-language**: English and Spanish support
- **Dual Theme**: Dark and Light mode
- **License Management**: Secure license activation system
- **Server Integration**: Cloud-based history and logging

## Installation 💾

### Download Installer (Recommended)
1. Download `PDF_Print_Manager_Setup_v1.0.0.exe` from Releases
2. Run the installer
3. Follow the installation wizard
4. Launch from desktop or start menu

## Requirements 📋

- Windows 10/11
- Adobe Acrobat Reader DC (recommended for best printing results)
